# 📊 Polars Series Exercise

**What it does:**
- Creates a Polars Series (1D array)
- Demonstrates basic Series operations
- Shows how to display Series data

**Key concepts:**
- `Series::new("name", &data)` - Create a Series
- Series is like a labeled array/column
- Polars is a fast DataFrame library (like pandas)
- `polars::prelude::*` - Import common Polars items

**Dependencies:** `polars` with default features

**Run:** `cargo run`
