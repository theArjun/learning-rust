# 📝 Basic Syntax

**Quick Notes:**
- Variables: `let x = 5;` (immutable) vs `let mut x = 5;` (mutable)
- Constants: `const MAX: u32 = 100;`
- Comments: `//` single line, `/* */` multi-line
- `println!("Hello {}", name);` for output
- Semicolons end statements
- Curly braces `{}` define blocks

**Run:** `cargo run`
