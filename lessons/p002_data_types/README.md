# 🔢 Data Types

**Quick Notes:**

- **Integers:** `i8`, `i16`, `i32`, `i64`, `i128`, `isize` (signed)
- **Unsigned:** `u8`, `u16`, `u32`, `u64`, `u128`, `usize`
- **Float:** `f32`, `f64`
- **Boolean:** `bool` (`true`/`false`)
- **Char:** `char` (4 bytes, Unicode)
- **String:** `String` (growable) vs `&str` (slice)
- **Arrays:** `[i32; 5]`, **Tuples:** `(i32, f64, char)`

**Run:** `cargo run`
