# 🔧 Functions

**Quick Notes:**
- **Definition:** `fn function_name(param: Type) -> ReturnType { }`
- **Parameters:** Must specify type: `fn add(x: i32, y: i32) -> i32`
- **Return:** Last expression (no semicolon) or `return value;`
- **No return type:** Function returns `()` (unit type)
- **Statements** vs **Expressions**: `let x = 5;` vs `5`
- Functions can be defined anywhere

**Run:** `cargo run`
