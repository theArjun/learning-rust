# 📚 Collections

**Quick Notes:**

- **Vector:** `Vec<T>` - growable array: `let v = vec![1, 2, 3];`
- **String:** `String` - growable UTF-8 text: `let s = String::from("hello");`
- **HashMap:** `HashMap<K, V>` - key-value pairs: `let mut map = HashMap::new();`
- **HashSet:** `HashSet<T>` - unique values: `let mut set = HashSet::new();`
- **Common methods:** `.push()`, `.pop()`, `.insert()`, `.remove()`
- **Iteration:** `for item in &collection { }`
- **Capacity:** `.with_capacity(n)` for pre-allocation

**Run:** `cargo run`
