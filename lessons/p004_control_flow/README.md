# 🔀 Control Flow

**Quick Notes:**
- **If:** `if condition { } else { }`
- **If let:** `if let Some(x) = option { }`
- **Loop:** `loop { break; }` (infinite), `while condition { }`
- **For:** `for item in collection { }`, `for i in 0..5 { }`
- **Match:** `match value { pattern => result, _ => default }`
- **Break/Continue:** Exit loop or skip iteration
- `if` is an expression: `let x = if condition { 5 } else { 6 };`

**Run:** `cargo run`
